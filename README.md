# cybersecurity-home-lab

Hands-on cybersecurity lab focused on developing real-world skills in:

- SOC analysis and threat detection
- Network segmentation and VLAN configuration
- Vulnerability scanning and remediation
- Governance, Risk, and Compliance (GRC) practices
- Home server and firewall deployment (OpnSense, Linux-based systems)
- Rent GPUs via cloud providers (e.g RunPod, Vast.ai ) for accelerated LLM experimentation

## Lab Goals

- Gain practical experience configuring secure environments
- Perform vulnerability assessments using open source tools
- Practice using tools like Wireshark, Nmap, Nessus, and Snort
- Document security controls, audit logs, and risk mitigation steps
- Prepare for certifications such as ISC2 Certified in Cybersecurity and CompTIA Security+

## Environment

- HP Z4 server (128 GB RAM, Xeon CPU)
- Kali Linux, Ubuntu Server, and other VMs via KVM
- Cisco 800 series routers and ME switches
- OpnSense firewall with segmented VLANs
